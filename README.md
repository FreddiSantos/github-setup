# github-setup

Versioned configuration for my GitHub workflow: bootstrap scripts, repository templates and automation.

> 🇧🇷 Configuração versionada do meu GitHub. O registro completo, em português, está em [SETUP.md](SETUP.md).

## Quick start

```powershell
powershell -ExecutionPolicy Bypass -File bootstrap\bootstrap.ps1
```

The script is idempotent: running it again leaves the same result.
